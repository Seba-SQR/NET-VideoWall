# NET-VideoWall

Software in development born from the idea of turning a group of Android TVs and a PC into a videowall with no additional hardware with the only requirement that they are in the same network.

## Requirements

The software is designed to work with a MediaMTX server, see [https://mediamtx.org/](https://mediamtx.org/)

For development it also requires GO, see [https://go.dev/](https://go.dev/)

## Development

1. **Clone the repository:**

```
git clone https://github.com/Seba-SQR/NET-VideoWall
```
2. **Run the project**

```
cd NET-VideoWall
go run .
```
